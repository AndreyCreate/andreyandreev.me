## 1. Токены

```css
:root{
  --bg:#FFFFFF;        /* фон страницы */
  --blue:#BFDDFB;      /* голубые плашки, карточки, секции */
  --blue-soft:#DCEBFC; /* светлые чипы на голубом */
  --blue-deep:#2F80ED; /* синяя линия под заголовком, моно-номера, ✓ */
  --coral:#E8563F;     /* CTA-пилюли, ✕, звёздочка ✳ у кикеров */
  --ink:#111111;       /* текст, тёмные бейджи */
  --ink-2:#3A3A3A;     /* основной текст карточек */
  --mute:#6B6B6B;      /* подписи, моно-кикеры */
  --line:#E6E6E6;      /* тонкие линии, границы */
  --gray:#F5F5F5;      /* серые секции и карточки */
  --yellow:#F5C445;    /* жёлтый маркер: @mbga_materials, жёлтая карточка таймлайна */
  --dark:#2B2B2B;      /* тёмная секция автора */
}
```

Чередование фонов сверху вниз: белый → белый (результаты) → серый (как устроено) → серый (примеры) → белый (для кого) → тёмный+градиент (автор) → белый (цена) → серый (FAQ) → белый (футер). Голубой — только плашки и карточки внутри, не целые секции (голубая секция была в первом мокапе, снята за длину).

## 2. Типографика

- Основной шрифт: **Inter** 400/500/600 (Google Fonts). Моно: **JetBrains Mono** 400/500.
- H1: `clamp(52px, 8.6vw, 124px)`, weight 500, `line-height .92`, `letter-spacing -.045em`, две строки, `white-space: nowrap` на десктопе; под второй строкой синяя линия 3px `--blue-deep` (`::after`, `bottom:-.02em`). На мобильном `16.5vw`, перенос разрешён.
- H2: `clamp(32px, 4.2vw, 58px)`, weight 400, `line-height 1.1`, `letter-spacing -.03em`. Ключевое слово — `<span class="u">` с синей линией 2px (`bottom:.04em`). Жёлтый маркер `<span class="hl-y">` только для `@mbga_materials`.
- Лид: `clamp(18px,1.5vw,21px)`, `--ink-2`; в hero 20px, начинается с моно `::` синим.
- Моно-кикер над H2: 12.5px, `letter-spacing .02em`, `--mute`, перед некоторыми — коралловая `✳`.
- Моно-мета «когда : / формат :»: ключ `--mute`, значение 13px, `line-height 1.55`, снизу линия `--line`.
- Тело карточек 16px / `line-height 1.45`; заголовки карточек 21–22px weight 500.

## 3. Компоненты

- **Пилюля** `.pill`: `border-radius 999px`, `min-height 54px`, `padding 0 34px`, моно 15px weight 500. Варианты: коралловая (белый текст), серая `#F3F3F3`/`--gray`, белая, чёрная. Hover: `translateY(-1px)`, `opacity .94`. Широкая коралловая в блоке цены `min-height 64px` + круг 64px со стрелкой ➤ справа.
- **Nav**: аватар 44px круглый + серый тег в две моно-строки «Новая группа / Андрея Андреева»; справа серая пилюля «Как устроено ➤» и коралловая «Оплатить участие».
- **Наклонённые карточки** `.card`: 190×(4/5), `border-radius 14px`, тень `0 20px 50px rgba(0,0,0,.18)`, повороты −6°/+7°/+5°/−4°, в углу «иконка карусели» (квадрат 22px, белая рамка 2px, тень 2px 2px 0 #fff). Внутри — `<video autoplay muted loop playsinline>` из `assets/*.mp4` (короткие анимации каруселей агента) или `<img>`.
- **Чипы-цифры** `.chip`: белые пилюли с моно 14px, тень `0 8px 24px rgba(0,0,0,.14)`, символы ♡ ⟳ ▷ перед числом. Цифры только реальные (см. §6).
- **Карточка результата** `.res-card`: `border-radius 18px`, `padding 26px`, `min-height 220px`; чередование серый/голубой (чётные голубые); моно-номер 01–06 синим (на голубом `#1f4f8a`); H3 21px; текст 16px.
- **Колонка недели** `.wk`: белая, `border 1px --line`, `border-radius 18px`; моно «Неделя N» синим; список строк с тонкими линиями; внизу голубая плашка «**Результат.** …» (`margin-top:auto`, чтобы все три плашки стояли на одной высоте).
- **Строка формата** `.fmt`: моно 13px `--mute`, каждый пункт с синей ✓.
- **Карточка примера** `.ex`: серая или голубая, `border-radius 18px`; превью 4:3 (`<video>` или постер), пилюля длительности слева внизу, коралловый круг ▶ справа внизу для видео; тело: моно-подпись «Кейс · дата», H3 21px, моно-строка результата, ссылка с подчёркиванием. Клик по `[data-video]` открывает модалку с Kinescope-iframe (16:9, `rgba(0,0,0,.82)` фон, Esc закрывает).
- **Чек-листы** `.checks`: строки с тонкими линиями, синяя ✓ / коралловая ✕ в моно.
- **Блок автора** `.author`: две колонки; слева `--dark`, имя латиницей `Andrey / Andreev` `clamp(48px,6.4vw,104px)` weight 500, моно-хэндл `@andreyandreev.me`, две цифры (40px weight 400) с моно-подписями; справа радиальные градиенты (`#F4B8A0`, `#E8563F`, `#F5D9A8`, `#BFDDFB` на `#F3D4C8`) и белая карточка «Статистика» (строки с тонкими линиями, зелёные ↗). Фото автора с чистым фоном пока нет — когда появится, ставить в правую колонку поверх градиента (как в референсе).
- **Цена** `.price`: слева название программы 54px + моно-строки (слово «Длительность:» коралловое) + дизеринг-фигура (CSS radial-gradient точки, clip-path); справа `:: 165 000 ₽` (`::` синим моно), моно «В стоимость включено:», список с линиями, широкая коралловая пилюля + круг.
- **FAQ**: `<details>`, `summary` 19px weight 500, «+»/«–» синим справа.
- **Футер**: тонкая линия сверху, «© Create Today», три ссылки с подчёркиванием.

## 4. Структура страницы (порядок и якоря)

1. `nav` → 2. `header.hero#top` (H1 две строки + мета «когда/формат» в две колонки под H1 → три колонки: карточки | лид + моно-подзаголовок | карточки → CTA-ряд: коралловая, серая, подпись «165 000 ₽ · до 8 участников»)
3. `#results` «Что у вас будет через три недели» — H2 + 6 карточек + одна строка-подпись
4. `#how` «Как это устроено» (серый) — H2 «Три недели, у каждой свой шаг» + лид + 3 колонки недель + строка формата
5. `#examples` «Так это выглядит в работе. Примеры из канала @mbga_materials» (серый) — 6 карточек
6. «Своими материалами и своими руками» — две колонки: «Вам сюда, если» ✓×6 / «Не подойдёт, если» ✕×4
7. `.author`
8. `#price` «Оплата и доступ»
9. `#faq` «Коротко о формате» — 5 вопросов
10. `footer`

Целевая высота: ≈ 8 100 px при 1440 (было 15 800 — Андрей: «до покупки не долистать»). Цена должна быть видна не позже шестого экрана.

## 5. Адаптив

- ≤ 980px: сетки в одну-две колонки, липкие колонки отключаются, карточки таймлайна/недель в столбик, блок автора в одну колонку.
- ≤ 640px: контейнер `padding 0 20px`; в nav скрыть тег и серую пилюлю; H1 `16.5vw`; пилюля статистики скрыта; группы наклонённых карточек `scale(.8)`; все сетки в одну колонку; в блоке цены круг со стрелкой скрыт, пилюля во всю ширину.
- Проверено: 1440 / 768 / 390 без горизонтального скролла.
