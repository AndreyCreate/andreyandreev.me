# Блок «Кейсы участниц» (MBGA)

Автономный блок кейсов участниц группы в DS v4 «белый лист». JS не нужен, все стили внутри `#mbga-cases`, поэтому с остальной страницей он не конфликтует.

## Как вставить на страницу
1. Сделать `git pull`: в репозитории параллельно работают другие агенты.
2. В `<head>` целевой страницы добавить `<link rel="stylesheet" href="/blocks/mbga-cases/cases-block.css">`.
3. Вставить разметку из `cases-block.html` (от `BEGIN` до `END`) в нужное место страницы. У всех картинок заменить `src="assets/` на `src="/blocks/mbga-cases/assets/`, тогда файлы копировать не нужно.
4. Шрифты Inter и JetBrains Mono на страницах сайта уже подключены. Если на странице их нет, взять ссылку Google Fonts из `<head>` превью.
5. Проверить на 1440, 768 и 390: горизонтальной прокрутки нет, каждая карточка открывает свой пост в канале.
6. Выкладывать через PR, как остальные правки сайта. Место на странице указывает Андрей.

## Как добавить новый кейс
Скопировать любую `<a class="mc-card">`. Карточка с классом `mc-wide` занимает две колонки, в блоке такая должна быть одна. Цвета карточек чередуются, классы `mc-dark`, `mc-blue` или без класса. Картинка — `assets/*.jpg`, ширина около 900 px.
