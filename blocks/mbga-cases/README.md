# Блок «Кейсы участниц» (MBGA)

Автономный блок кейсов участниц группы в DS v4 «белый лист». JS не нужен, все стили внутри `#mbga-cases`, поэтому с остальной страницей он не конфликтует.

## Как вставить на страницу
1. Скопировать `cases-block.css` и папку `assets/` рядом со страницей (или поправить пути).
2. В `<head>` подключить стили: `<link rel="stylesheet" href="cases-block.css">`. Шрифты Inter и JetBrains Mono на страницах сайта уже подключены.
3. Вставить разметку из `cases-block.html` (от `BEGIN` до `END`) в нужное место страницы.

## Имена
Имена (Мальцева, Фёдорова, Херд) стоят только там, где они уже опубликованы в канале и на /mbga/. Участниц из постов /240 и /244 в канале не называли, поэтому в блоке они тоже без имён.

## Как добавить новый кейс
Скопировать любую `<a class="mc-card">`. Цвета карточек чередуются, классы `mc-dark`, `mc-blue` или без класса. Картинка — `assets/*.jpg`, ширина около 900 px.

Превью: https://andreyandreev.me/blocks/mbga-cases/ (закрыто от поисковиков).
