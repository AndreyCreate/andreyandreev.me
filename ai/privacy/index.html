Автоматизированная обработка — обработка персональных данных с помощью средств вычислительной техники.

Блокирование — временное прекращение обработки персональных данных, кроме случаев, когда обработка необходима для их уточнения.

Обезличивание — действия, после которых невозможно без дополнительной информации определить принадлежность персональных данных конкретному Пользователю.

Уничтожение — действия, в результате которых персональные данные уничтожаются безвозвратно.

Cookies — небольшие фрагменты данных, которые сайт сохраняет в браузере Пользователя и которые браузер отправляет сайту при последующих запросах.
